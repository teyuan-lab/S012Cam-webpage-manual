# S012Cam website and manuals

Bilingual support and privacy pages for the S012Cam iPhone app.

Website: https://teyuan-lab.github.io/S012Cam-webpage-manual/

App Store: https://apps.apple.com/app/id6834323253

The site is static HTML/CSS/JavaScript, published by GitHub Pages from main at the repository root. No build service or external front-end dependencies are required.

English and Traditional Chinese manual sources are in `manuals/`. Published PDFs are in `assets/`. The camera reference uses the approved original iPhone 16 Pro screenshot with numbered document annotations.

To rebuild the manuals, run `python3 manuals/build_manuals.py` with ReportLab installed. The script uses macOS Arial Unicode and embeds its glyphs. Run `python3 build_site.py` to rebuild the web manuals and chapter pages. Update the font path when building on another operating system.

## Preview the multipage website

The bilingual pages share `site_shell.py` and `style.css`. Main page content is in `content/en/` and `content/zh/`. Update the Markdown sources in `manuals/` for the full manual and chapter pages.

Run `python3 build_site.py` to build all static website pages, manual chapter pages and the complete web manuals. Run `python3 manuals/build_manuals.py` with ReportLab and the documented font to update the PDF downloads. Rebuild both when manual content changes.

The main navigation links to polarization, app, Rotator, manual, buying and support pages. The manual separately groups iPhone support (handheld/fixed) and capture modes (Gyro/Timer). The buying page offers email enquiries for the DIY and fully assembled versions; no price, stock or checkout service is assumed.

The old complete manual HTML and PDF URLs are preserved. Former home-page section links redirect to the corresponding new pages via `language.js`.

### Instruction media

The illustrated manuals retain 16 reusable diagrams and comparison photographs from the supplied earlier manuals, alongside the current 2.0 camera and results screenshots. The MagSafe drawing shows the current five-pad plate; old direct-to-phone pad instructions are not used.

### Polarization lesson

The English and Traditional Chinese polarization pages cover eleven topics, with 19 numbered figures per language, six practical experiments, eighteen application examples and six interactive teaching models. Explanations include links to the supporting optics, instrument-manufacturer and atmospheric-science sources. The source fragments live in `content/en/polarization.html` and `content/zh/polarization.html`; browser interactions are in `polarization.js`.

Original vector diagrams and ideal Fresnel, Rayleigh and Malus-law curves can be regenerated with `tools/build_polarization_figures.py` (NumPy, Matplotlib and the configured CJK font). SVG assets are tracked, so ordinary page builds do not require those plotting packages. App pages use Apple's unmodified official App Store download badge and the app record `id6834323253`.

The app page introduces purpose, features and actual result examples. Detailed capture workflows, controls and file instructions belong to the user manual.

Sky examples compare 15°, 45° and 75° solar elevation with a fixed observer and view. AoLP/DoLP examples are generated by `tools/build_polarization_metrics.py`. External sky imagery is credited and licensed in its figure caption; original files are retained without image edits.

`wave-demo.js` implements Fig. 1 as a vacuum plane wave with `cB = z-hat × E`, a single orthographic camera, state selection, pause/reset and time-phase control. It respects reduced-motion preferences and stops rendering off screen. Fig. 4 and the reflection experiment share `drawReflectionGeometry` in `polarization.js`; their field amplitudes follow the same Fresnel model and 0–89° slider.

The arbitrary fully polarized state uses ellipse azimuth ψ and signed ellipticity χ, with semiaxes cos χ and |sin χ|. Positive χ is left-handed and negative χ is right-handed when viewed from the receiver towards the source (−z), following the linked optical convention. Circular states disable ψ because the major-axis orientation is undefined.

The projector example uses parallel red/blue electric-field axes and an orthogonal green axis. Statistical field samples animate Fig. 3. Fig. 11 uses the ideal vector projection `Eout = (Ein · T)T` for vertical input. Its field waves reach the sheet plane; Fig. 11(c) includes a synchronized `cos²θ` curve, where θ is the input-field/transmission-axis angle. LCD observations are grouped in the LCD section with selectable source axes. Applications follow the measurement concepts and include glare reduction, gloss, scattering correction and material detection.

Rayleigh Fig. 8 is interactive in `lesson-demos.js`. Incident propagation is +z. Readers can select unpolarized input or linear input with direction α in x–y, then vary scattering angle Θ and azimuth φ. Linear output is the coherent transverse field projection, with DoLP 1 except at zero-intensity radiation nulls where polarization is undefined. The field views, intensity and DoLP curve markers share this model.
